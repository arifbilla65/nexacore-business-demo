# NexaCore Business Website Demo
Portfolio-grade static business website demo developed for Arif Billa.

## Live deployment
This repository is configured for GitHub Pages deployment from the `main` branch.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before using for a real client
- Replace the fictional NexaCore brand and demo statistics/testimonial.
- Replace hello@example.com with the client's real contact email.
- Connect the contact form to a real backend/form service.
- Add privacy/cookie terms if applicable.

The current site is explicitly labeled as a portfolio demonstration and does not claim fictional work as real client work.
